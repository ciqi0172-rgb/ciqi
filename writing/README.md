# 考研英语一 · 大作文表达训练室

本学习站从模板内化出发，训练从模板套用到灵活表达的迁移能力。

## 访问
GitHub Pages 子目录： https://ciqi0172-rgb.github.io/ciqi/writing/

## 内容结构
- 学习路线：从认主题、找角度、搭逻辑到独立写作
- 我的模板：正向现象、讽刺/社会问题、双主体/双视角、图表作文
- 主题语料库：个人成长、社会价值、文化交流、学习教育、科技生活、选择与就业
- 逻辑与升华：第二段递进展开、第三段主题呼应
- 句子迁移训练：句子功能识别、句型迁移、模板适配判断
- 真题示范拆解：毕业生选择、2007点球寓言、文化火锅
- 独立表达练习：主题句、论证角度、结尾呼应与自检清单

## 使用说明
纯静态 HTML，无需构建工具。学习进度和练习草稿保存在当前浏览器的 localStorage 中，不会上传到服务器。
