# 考研英语一 · 大作文表达训练室

## 访问
- 学习目录与模板库：https://ciqi0172-rgb.github.io/ciqi/writing/
- 课程式逐步带练：https://ciqi0172-rgb.github.io/ciqi/writing/course.html

## 两个学习入口
### 学习目录
模板库、主题语料索引、逻辑与升华、句子迁移练习、真题范文拆解、独立表达练习。

### 课程式带练
- 第一段图画描述：人物、动作、位置、细节、图下注释等语料；多组句子从信息提取到拼接的完整示范
- 正向图画：主题词、具体行为、浅层价值、深层社会意义、结尾意象呼应
- 负面图画：行为、直接危害、递进后果、价值取舍、公共责任
- 图表作文：读图步骤、趋势句拼接、双图表解读、数据与主题之间的逻辑、2026养老机器人示范、大学生课余时间趋势示范
- 其他题材迁移：毕业生选择、2007点球寓言、跨专业讲座、志愿服务
- 老师带练：分步骤练第一段、第二段、第三段，并可展开参考过程

## 学习原则
先背熟原模板，再识别句子功能；先替换内容，再调整逻辑；最后练习重组和独立表达。图表分析不得编造数据，图画描述不得添加画面中不存在的信息。
