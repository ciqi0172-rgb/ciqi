一、英语一大作文

核心任务：描述图画 / 图表，概括趋势或现象，分析原因、影响与意义，提出建议或展望。重点是“能组成句子、能迁移到不同题材”，而不是孤立的生僻名词。

1. 图表描述与数据变化

表达中文 / 使用场景
figure / statistic数据；统计数字。图表描述常用。
percentage / proportion百分比 / 比例。饼图、占比描述。
account for占……比例；说明某部分所占份额。
respectively分别地。按前文列举顺序对应数据。
overall总体来看。引出总体特征，不重复具体数字。
increase / rise / grow上升、增长。按语境选择，不必堆同义词。
decline / decrease / fall下降、减少。
sharply / significantly / gradually急剧地 / 显著地 / 逐渐地。只有图表支持时使用。
reach a peak达到峰值。
remain stable保持稳定。
comparison比较；用于不同类别或时期对照。
survey调查；调查结果。
total总数；总计。

模板使用提醒：以上是可调用的语料库，不是要求一篇作文全部塞进去。我们的模板中，图表段优先保证“图画核心动作 + 图表总体特征 + 具体数据”；第二段围绕一条清晰因果链展开；第三段再上升到个人或社会意义并给出合理建议。没有图表依据的数字、因果和结论不要补写。

二、英语一小作文

核心任务：完成交际目的。小作文优先背“动作动词 + 固定搭配 + 礼貌表达”，而不是大作文的宏观社会价值词汇。

三、原词表中建议剔除或降级的内容

“绝对用不到”严格来说不能对未来所有题目作百分之百保证。这里的“剔除”指：不值得作为考研写作专项词汇背诵，不是说阅读中永远不会出现。

1. 直接剔除：日常物品、居家设施与零散生活名词

如 sofa、fridge、bedroom、shower、washing machine、air conditioner、chopsticks、dining table、furniture、icebox、villa、apartment、living room、microwave oven、porcelain 等。除非题目明确涉及某一物品，否则几乎不能承担大作文论证或小作文交际功能。

2. 直接剔除：具体节日、娱乐活动与饮食细节

如 Christmas Eve、Christmas Day、Thanksgiving Day、Labor Day、moon cake、watch fireworks、make dumplings、kite、skating、riding、swimming、jogging、gardening、playing table tennis、playing tennis、takeout 等。一般不作为写作核心词汇记忆。

3. 直接剔除：文学人物、作品专名和历史文化专名清单

如 Shakespeare、Einstein、Santa Claus、Sun Wukong、Zhu Bajie、Zhuge Liang、Xue Baochai，以及 Swan Lake、Water Margin、Journey to the West、The Great Wall、Tsinghua University、the Ming Dynasty、the Northern Song Dynasty 等。专名应在题目确实涉及时再查，不应占据通用写作背诵量。

4. 直接剔除：过度具体的职业、专业缩写和冷门名词

如 MA、MS、MBA、MPAcc、driver、painter、merchant、opera、alley、compass、anchor、gunpowder、mileage、washer、streamer（原词表释义与直播语境不符）等。若题目需要，使用更通用、准确的词替代。

5. 降级而非彻底删除：题材窄、表达笨重或重复的词

例如 traffic jam / heavy traffic 可优先掌握 traffic congestion；mental fitness、psychological fitness、mental health 等不要重复背成多个同义条目；well-developed transit system 与 well-developed transportation system 只需掌握一种；ill-treat、mistreat、maltreat 不必三套并背；the aged、senior citizens、the elderly 选 the elderly 作为主力表达即可。

6. 保留但只作识别，不要求主动输出

部分学科名、学历名称、政策术语和历史文化词汇，如 ecosystem、deforestation、tax relief、compulsory education、doctoral degree 等，可能在特定题材中有用，但优先级低于上面的大作文主题词与小作文功能表达。

四、怎么背，才能真正写得出来

  1. 先背搭配，不孤立背单词。例如 responsibility → a sense of responsibility → undertake responsibilities。
  2. 每个主题只抓能迁移的核心表达。教育、个人成长、社会责任、文化传承、环境、科技与经济，是大作文的主干。
  3. 小作文按交际目的背。邀请、请求、感谢、道歉、建议信、投诉、通知、申请分别整理，不和大作文混背。
  4. 把词放回我们的模板。先确定中文逻辑，再选择英文词和搭配，最后形成句子；不要先找高级词再硬塞进作文。
  5. 数据描述只写图中给出的信息。比例不是增长率，百分比不是百分点；没有给出的时间、原因和样本信息不能臆造。

本词表是从原始911条中筛选出的写作实用版，不是词汇量越大越好。少量高频、可迁移、能准确造句的表达，比背一长串低概率专名更有价值。
