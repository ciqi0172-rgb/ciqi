# 考研英语一 · 15篇外刊精读

独立静态阅读站，收录15篇英文原文及原有段落编号。

## 当前功能

- 文章目录可折叠，收起后扩大文章阅读区域
- 原文阅读、段落已读、收藏、全文搜索与阅读进度
- 字号、行距和深色模式设置
- 原文断句标记：开启标记模式后点击句中位置插入斜杠；再次点击斜杠可删除。标记保存在当前设备，不修改原文
- 精读成果栏目：目前已完成第1篇，包含13段参考翻译、分类词汇表、全文逻辑地图、长难句拆解、阅读易错点和精读题目

阅读进度、收藏和断句标记保存在当前设备的浏览器本地存储中。
