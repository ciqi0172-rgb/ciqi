分论点组装

检查重点：回应题意、角度区分、材料依据、对策可执行性。

快速论证骨架

观点 → 解释

这件事为什么重要？它解决了什么核心矛盾？

解释 → 作用机制

通过什么环节产生影响？不要只写“有利于”。

作用 → 结果

对群众、治理、产业或长远发展具体带来什么变化？

观点→原因 / 机制→具体影响→回扣题目

素材与模板库

原资料里的背景句、影响表达、对策模板、人物事例、名言和文章收尾集中检索。

如何调用素材

背景句：交代时代语境后，尽快转入具体问题。

影响句：拆出“对象 / 举措 → 直接作用 → 长远价值”，按材料删选。

人物事例：行动事实 → 体现的品质或机制 → 能证明的分论点。

名言：先确认含义，再说明与观点的关系；名言不能代替论证。

模板：保留句子骨架，替换成题干中的对象、行动和结果。
